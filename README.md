Student Portal – Student & Faculty Management System

This is a simple student portal application built using React.js and Firebase.
It includes the following features:

🔹 Features

Student login page

Dashboard

Add / Update / Delete Students

Faculty management

Firebase Firestore backend

Clean UI with CSS
